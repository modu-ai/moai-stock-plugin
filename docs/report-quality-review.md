# 설치 후 보고서 비교 및 원인 분석

비교 대상: 사용자가 첨부한 report.html과 승인본 reports/sk-hynix-review/report.html. 첨부 파일은 설치 검증 ZIP의 report.html과 바이트가 동일합니다. 이 검토는 결과물·생성기·입력 지침·기존 조사 기록의 비교입니다. 모든 원뉴스와 공시를 이번에 다시 읽은 전수 사실 검증은 아닙니다.

## 플러그인 수정

1. 문단별 논지·근거·원리·반론·투자자 의미를 검토하는 편집 게이트를 명시했습니다. 7~9문장·450~700자는 승인본의 편집 참고 범위이며 사실 부족을 반복 문장으로 채우는 기준이 아닙니다. 최소 5문장 기준은 유지합니다.
2. 렌더러가 모든 문단을 5문장으로 끝내거나 짧은 문단으로 작성한 경우, 판단 범위·근거 있는 편집 검토가 누락된 경우 editorial_quality 경고를 남깁니다. 구조 통과와 내용 품질 인증을 구분합니다.
3. 안전한 highlights 필드를 추가해 본문의 주요 숫자와 판단을 강조합니다. HTML 태그를 실행하지 않고 원문 내 정확한 부분 문자열만 허용합니다.
4. 입력 JSON·출처 장부·구조검증 JSON을 HTML에 다운로드 데이터로 내장했습니다. 별도 파일과 원본 SHA-256도 유지합니다.
5. 관심목록 판단은 research_priority로 명시하고, 가격 적정성·개인 계좌 비중과 분리합니다. 담당자의 중요 논거를 최종 문단에 연결하는 coverage 검토와 후속 공시 탐색을 강화했습니다.

## 검증과 남은 범위

새 생성기의 회귀 시험으로 강조 안전성·단일 HTML 자료 다운로드·최소 분량 경고를 확인합니다. 기존 생성 입력의 재렌더는 디자인과 파일 전달 개선 검증이며 새로운 조사 결과가 아닙니다. 기존 관망 결론이나 실제 수치는 임의로 바꾸지 않습니다. Goose 커맨드·서브 에이전트·goosekr 총괄 지침은 패키지에 추가했으며 실제 호스트가 제공하지 않는 네이티브 팀 실행을 보장하지 않습니다. 업데이트 후 새 조사 실행의 내용 품질은 다시 검토해야 합니다.
