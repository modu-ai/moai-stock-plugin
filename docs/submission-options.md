# 공식 디렉터리와 배포 경로

확인일: 2026-10-16. 현재 기본 배포는 GitHub 마켓플레이스 연결이며, 등록이 불가능한 계정에는 전용 ZIP을 보조 제공합니다. 공개 퀵스타트는 ChatGPT 웹과 Claude 웹만 안내합니다.

| 구분 | 확인한 경로 | 현재 상태 |
|---|---|---|
| Claude 공식 디렉터리 | 개발자 포털에 저장소·브랜치와 플러그인 경로를 제출하고 검증·심사 후 공개 | 제출 가능 경로 확인. 실제 제출·승인 없음 |
| OpenAI 공식 플러그인 디렉터리 | 검증된 개발자 신원을 선택하고 ZIP 업로드, 검증·제출·공개 | 스킬 전용 패키지 지원 확인. 실제 제출·승인 없음 |
| Claude 웹 GitHub 설치 | 사용자 지정 → 플러그인 → 마켓플레이스 추가 → 저장소 동기화 | 0.1.1 실제 설치와 Skills 8개 확인 |
| ChatGPT 웹 GitHub 설치 | 워크스페이스 관리자 Admin Console의 Import marketplace | 공식 문서 확인. 실제 관리자 설치 미검증 |
| ChatGPT 웹 ZIP 설치 | 개인 플러그인 압축 업로드 → 설치 | 0.1.1 실제 설치와 스킬 8개 확인 |

Claude 공식 제출은 개발자의 GitHub 저장소를 원본으로 읽습니다. 수강생이 사용자 지정 마켓플레이스를 연결하는 절차와는 다릅니다. OpenAI 공식 제출은 검증된 개발자 신원 등 포털 요건을 충족해야 합니다. 호스트 설치 성공만으로 공식 디렉터리 승인을 받은 것으로 표시하지 않습니다. 연락처·게시 국가·법적 확인 등 제출자 정보는 임의로 작성하지 않습니다.

아이콘은 승인된 모두의 주식 글자 로고를 정사각형 투명 PNG로 제공합니다. OpenAI의 logo·composerIcon과 Claude의 공식 디렉터리 icon 필드에 연결했습니다. Claude의 사용자 마켓플레이스 화면은 호스트가 해당 필드를 표시하는지 별도 확인해야 합니다. 보고서의 가로 로고는 유지합니다.
