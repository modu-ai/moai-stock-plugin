# Goose 통합 스킬 설치

배포 파일은 dist/goose-0.3.0.zip 하나입니다. 내부 스킬 7개와 총괄·호환 지침, 계산기·생성기·로고를 포함합니다. 마켓플레이스를 연결할 필요가 없습니다.

- ChatGPT: 공식 Skills 안내의 Create → Upload from your computer 경로를 사용합니다. 계정에 따라 Skills 탭이 보이지 않을 수 있으며 스킬 편집기 접근과 ZIP 업로드 성공은 따로 확인합니다.
- Claude: 사용자 지정 → Skills → Skill 추가 → Skill 업로드에서 ZIP을 선택하고 업로드합니다.
- 업데이트: 새 ZIP을 수동으로 올리고 버전을 확인합니다. 기존 0.1.x 플러그인과 중복 실행하지 않습니다.

설치 검증 기록은 작업별 확인 결과를 추가합니다. 네이티브 에이전트·원문 검색·Python 실행은 호스트 지원 여부에 따릅니다.
