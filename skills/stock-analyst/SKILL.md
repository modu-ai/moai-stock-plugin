# 자연어 요청을 분석 작업으로 연결

먼저 [실행 지도](../stock-report/references/workflow-map.json), [조사 계약](../stock-report/references/research-contract.md), [역할 계약](../stock-report/references/agent-team.md)을 읽습니다. 사용자는 스킬 이름을 외울 필요가 없습니다. 종목·목적·기준일을 확인하고 자연어 의미를 실행 지도에 대응시킵니다. 단순 용어 질문이면 필요한 짧은 설명만 제공합니다.

1. 단일기업 전체분석, 다기업 비교, 발표실적, 공시/뉴스사건, 이전판단 재점검, 주장검증, 보유자산 상담을 구분합니다. 복합 요청은 필요한 흐름을 합치고 같은 자료를 중복 수집하지 않습니다.
2. 스킬 매핑과 필요한 입력/결과를 사용자에게 짧게 안내합니다. 계좌는 평단가·수량만으로 적정비중을 결정하지 않습니다. 종목 식별이나 필수자료가 없으면 필요한 것만 묻고 독립 조사부터 진행합니다.
3. 실제 지원되는 스킬/에이전트 도구를 사용합니다. 하위 스킬은 leaf 실행으로 담당 결과를 돌려주고 이 총괄을 재호출하지 않습니다. 분석 후 독립 팩트체크, 수정, 최종 편집을 연결합니다.
4. 사용자 요청에 맞는 최종 보고서와 출처·한계를 보여줍니다. 정기 모니터·계좌 거래·공개 게시·플러그인 배포를 자동으로 실행하지 않습니다. 기존 보고서가 없는 재점검은 새로운 기준선을 만들고 과거판단을 창작하지 않습니다.

실행 지도는 의도 해석의 기준이며 기계적 키워드 일치가 아닙니다. 한 질문에 맞지 않는 모든 스킬을 호출하지 않습니다. 네이티브 체이닝 API가 없으면 각 지침을 읽어 동일한 입력/출력 계약으로 수행하고 실제 수행 방식을 기록합니다.
