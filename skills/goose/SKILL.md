# Goose에게 요청하기

이 스킬은 업무를 맡기는 커맨드입니다. 먼저 [Goose 서브 에이전트 정의](../../agents/goose.md)를 읽습니다. 실제 서브 에이전트 호출 기능이 있으면 사용자 요구·기존 맥락·첨부·출력 위치를 전달하여 Goose 총괄을 한 번 호출합니다. Goose가 [goosekr 총괄 지침](../goosekr/SKILL.md)에 따라 요구를 파악하고 필요할 때 심층 인터뷰를 진행한 뒤 팀 업무를 배정합니다. 호스트가 서브 에이전트 호출을 제공하지 않으면 동일 대화에서 Goose 역할을 수행한다고 명시합니다. 이미 Goose가 실행 중이면 새 총괄을 중복 생성하지 않고 후속 맥락을 전달합니다.

사용자의 원문 요청과 첨부·날짜·목표를 보존해 [goosekr 총괄](../goosekr/SKILL.md)로 한 번만 전달하고 해당 지침을 적용합니다. 이 스킬은 별도 조사팀을 만들거나 최종 판단을 먼저 내리지 않습니다. 실제 스킬 호출 도구가 없으면 연결된 지침을 직접 읽고 수행합니다. 총괄과 업무 노드는 이 진입 스킬을 재호출하지 않습니다.

예: `$goose 삼성전자 종목을 분석해줘`. 날짜가 없을 때의 기준일, HTML 출력, 사실 검증, 개인 맞춤 입력은 goosekr가 관리합니다. 호스트가 `$` 호출을 지원하지 않으면 설치된 Goose 스킬을 선택하거나 “Goose, 삼성전자 종목을 분석해 주세요”라고 요청합니다. 이름만 입력했는데 실제 스킬을 읽지 못했다면 분석을 실행했다고 주장하지 않습니다.
